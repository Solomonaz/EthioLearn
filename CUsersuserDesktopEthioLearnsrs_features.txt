4.1 Authentication System The authentication system is the gateway to EthioLearn. Given Ethiopia&#x2019;s mobile-first digital landscape, the system uses phone number-based authentication as the primary method, with optional email support for institutional users. 4.1.1 Registration Flow User selects their role: Student, Parent, or Institutional (Admin/Teacher). User enters their phone number (Ethiopian format: +251XXXXXXXXX). System sends a 6-digit OTP via SMS (valid for 5 minutes, max 3 retry attempts). User enters OTP for verification. On first login, user completes profile setup: name, school, grade (for students), or school affiliation (for admins). System generates a JWT token pair (access token: 15 min, refresh token: 30 days). 4.1.2 Security Requirements Rate limiting: Maximum 5 OTP requests per phone number per hour. Account lockout: After 5 failed OTP attempts, account is locked for 30 minutes. Token rotation: Refresh tokens are single-use; each refresh issues a new pair. Phone number validation: Only Ethiopian phone numbers (+251) accepted at launch. Session management: Users can view and revoke active sessions from their profile. Data encryption: All sensitive data encrypted at rest (AES-256) and in transit (TLS 1.3). 4.1.3 Social/Alternative Login (Phase 2) In future iterations, the system will support Telegram login (widely used in Ethiopia) and Google Sign-In for students with Google Workspace school accounts. 4.2 Admin Dashboard The Admin Dashboard is the command center for school administrators and super admins. It provides full visibility and control over every aspect of the platform within the admin&#x2019;s scope (school-level or system-wide). 4.2.1 Dashboard Home / Overview The dashboard home screen displays key metrics at a glance through interactive cards and charts: Total registered students (with daily/weekly/monthly trend graph) Total active students in the last 7 days Total quizzes taken this week/month (bar chart by subject) Average quiz score across all students (gauge chart) Top 10 students by points (mini leaderboard widget) Textbook upload status: total books, pending processing, active System health indicators: API uptime, AI service status, SMS delivery rate 4.2.2 User Management Module Administrators can manage all user accounts within their school: View, search, and filter all students by grade, section, or enrollment date. Activate, deactivate, or suspend student accounts. Bulk import students from CSV/Excel files with columns: name, phone, grade, section. Assign teacher roles and link teachers to subjects. Reset student passwords/OTP locks. View login history and last active timestamps. 4.2.3 Textbook Management Module Detailed in Section 4.4, but from the admin perspective: Upload new textbooks (PDF or EPUB) with metadata: title, grade, subject, year, edition. Organize textbooks by grade and subject in a hierarchical structure. Monitor AI processing status for each uploaded book. Preview generated chapter outlines and approve/reject them. Set textbook visibility: active, draft, or archived. 4.2.4 Analytics &amp; Reports Module Comprehensive analytics to drive data-informed decisions: Student Performance Report: filter by grade, subject, chapter, or time period. Exportable as PDF or CSV. Subject Difficulty Heatmap: visual matrix showing average scores per chapter across all grades. Engagement Report: quiz completion rates, average time per question, drop-off points. Comparative Analysis: compare performance across sections, grades, or time periods. Reward Distribution Report: points allocated, rewards claimed, budget tracking. 4.2.5 Reward Configuration Module Admins configure the reward system to incentivize learning: Define reward tiers: Bronze (500 pts), Silver (1500 pts), Gold (3000 pts), Platinum (5000 pts). Assign rewards to tiers: certificates, school supplies, books, or custom prizes. Set reward redemption windows (e.g., monthly, quarterly, per semester). Track reward inventory and budget allocation. Approve/deny individual reward claims. 4.2.6 Game &amp; Competition Management Create school-wide quiz tournaments with custom rules and schedules. Set competition windows (e.g., &#x201C;Exam Week Challenge&#x201D;). Configure group game settings: max players, time limits, difficulty locks. Monitor live games in progress with spectator view. 4.3 Student Dashboard The Student Dashboard is designed as a gamified, mobile-first experience that makes learning feel like progression in a game. Every element is designed to motivate continued engagement. 4.3.1 Dashboard Home Welcome banner with motivational message (rotates daily, localized to student&#x2019;s language). XP Level Indicator: visual progress bar showing current level (e.g., Level 12 — Scholar) with XP needed for next level. Today&#x2019;s Challenge: a daily quiz challenge (5 questions from a random subject) for bonus points. Streak Counter: consecutive days of quiz activity. Streaks unlock streak-specific badges. Quick Stats: total quizzes taken, average score, current rank in school, total points. Recent Activity Feed: last 5 quizzes with scores and time taken. 4.3.2 Quiz Launcher The quiz launcher guides students through a structured selection process: Select Grade: dropdown populated with available grades (1–12). Select Subject: filtered list of subjects available for the chosen grade (e.g., Biology, Mathematics, Chemistry, History, Amharic). Select Chapter: list of chapters from the selected subject&#x2019;s textbook, with completion indicators. Select Difficulty: Easy (definitions, recall), Medium (application, short analysis), Hard (critical thinking, multi-step), or Mixed. Select Question Count: 5, 10, 15, 20, or custom number. Select Mode: Solo Practice, Timed Challenge, or Group Battle. 4.3.3 Performance Tracking Subject-wise score breakdown with trend graphs over time. Chapter mastery map: color-coded grid showing mastery level per chapter (Not Started, In Progress, Proficient, Mastered). Weakest Topics list: AI-identified chapters where the student consistently scores below 60%. Study Recommendations: AI-generated suggestions like &#x201C;You should review Chapter 5 of Biology — your last 3 attempts averaged 45%.&#x201D; 4.3.4 Achievements &amp; Badges A badge system encourages diverse engagement patterns: First Quiz — Complete your first quiz. Speed Demon — Complete a 10-question quiz in under 3 minutes. Perfect Score — Answer all questions correctly in a quiz. Streak Master — Maintain a 7-day quiz streak. Social Butterfly — Play 10 group games. Subject Champion — Achieve &#x201C;Mastered&#x201D; status in all chapters of one subject. Knowledge Sharer — Upload 3 books to the platform. Cross-Subject Scholar — Take quizzes in 5 different subjects in one week. 4.4 Textbook Management The textbook management system is the content backbone of EthioLearn. It handles the ingestion, processing, and organization of educational content that fuels the entire question generation engine. 4.4.1 Upload Workflow Admin navigates to Textbook Management and clicks &#x201C;Upload New Textbook.&#x201D; Admin fills in metadata: Title, Grade, Subject, Academic Year, Edition, Publisher, Language. Admin uploads the file (supported formats: PDF, EPUB; max size: 100MB). System validates the file: checks format integrity, scans for corruption, verifies page count. AI Processing Pipeline begins (asynchronous): OCR (if scanned PDF), text extraction, chapter detection, content indexing, topic classification. System generates a chapter outline and presents it to the admin for review. Admin approves the chapter structure (with ability to rename, merge, split, or reorder chapters). Textbook status changes to &#x201C;Active&#x201D; and becomes available for quiz generation. 4.4.2 AI Processing Pipeline Details When a textbook is uploaded, the AI pipeline performs the following operations: OCR Layer:  For scanned PDFs, Tesseract OCR with Amharic/English language packs extracts text. Confidence scores below 80% flag pages for manual review. Chapter Detection:  NLP algorithms analyze heading patterns, page numbers, and formatting cues to automatically detect chapter boundaries. Content Chunking:  Each chapter is split into semantic chunks of 500–1000 tokens, optimized for LLM context windows during question generation. Topic Tagging:  Each chunk is tagged with Bloom&#x2019;s Taxonomy levels (Remember, Understand, Apply, Analyze, Evaluate, Create) for difficulty mapping. Embedding Generation:  Vector embeddings are generated for each chunk and stored in a vector database for semantic search during question generation. 4.4.3 Content Organization Textbooks are organized in a strict hierarchy that mirrors the Ethiopian education structure: Grade (1–12) → Subject (e.g., Mathematics, Biology) → Textbook (specific edition) → Chapter → Topic/Section This hierarchy is critical because students navigate quizzes using this exact path. Each node in the hierarchy stores metadata including total questions generated, average difficulty, and usage statistics. 4.5 AI-Powered Exam Generation The question generation engine is the intellectual core of EthioLearn. It uses large language models (LLMs) to generate pedagogically sound, curriculum-aligned questions from textbook content. 4.5.1 Question Generation Flow Student selects grade, subject, chapter, difficulty, and question count. System retrieves relevant content chunks from the vector database using semantic search. System constructs a detailed prompt for the LLM, including: the content chunks, desired difficulty level mapped to Bloom&#x2019;s Taxonomy, question format (MCQ, True/False, Fill-in-the-Blank), Ethiopian curriculum context, and the language preference. LLM generates questions with: the question text, four answer options (for MCQ), the correct answer, a detailed explanation for the correct answer, and a difficulty score (1–5). System applies post-processing: deduplication against existing question bank, difficulty validation, grammar check, and answer consistency verification. Questions are cached in the question bank for future reuse (reducing API costs). Student receives the quiz and begins the game. 4.5.2 Question Types Type Format Example Domain MCQ 4 options, 1 correct All subjects; primary question type True/False Binary choice Science facts, historical claims, definitions Fill-in-Blank Complete the sentence Language subjects, formulas, key vocabulary Match Pairs Connect related items Vocabulary, historical dates, scientific terms Ordering Arrange in sequence Historical events, scientific processes, math steps 4.5.3 Difficulty Calibration The system maps difficulty levels to Bloom&#x2019;s Taxonomy to ensure pedagogical rigor: Level Bloom&#x2019;s Level Question Characteristics Easy Remember, Understand Direct recall from text; definitions; simple identification. Points: 10 per correct answer. Medium Apply, Analyze Application of concepts; comparing ideas; short reasoning. Points: 20 per correct answer. Hard Evaluate, Create Critical thinking; synthesis of multiple concepts; multi-step reasoning. Points: 30 per correct answer. 4.5.4 Question Quality Assurance Every generated question passes through a multi-layer quality pipeline: Relevance Check: Ensures the question is derived from the selected chapter content (cosine similarity threshold: 0.75). Answer Validation: Verifies the correct answer is unambiguously correct and distractors are plausible but clearly wrong. Difficulty Verification: Cross-checks the assigned difficulty against Bloom&#x2019;s Taxonomy keywords in the question. Duplicate Detection: Compares against the existing question bank using semantic similarity to avoid repetitive questions. Language Quality: Grammar and clarity check for both Amharic and English questions. Teacher Review Queue: Flagged questions (low confidence score) are sent to teachers for manual review before entering the active bank. 4.6 Solo &amp; Group Game Modes The game engine is what makes EthioLearn uniquely engaging. It transforms traditional quizzing into competitive, rewarding gameplay experiences. 4.6.1 Solo Practice Mode Solo mode is a low-pressure environment for self-paced learning: No time limit per question (optional timer can be enabled by the student). Immediate feedback after each question: correct/incorrect indicator plus detailed explanation. Points awarded per correct answer based on difficulty (Easy: 10, Medium: 20, Hard: 30). Bonus points for streaks: 3 correct in a row = 1.5x multiplier, 5 in a row = 2x multiplier. At quiz completion: score summary, correct/incorrect breakdown, time taken, points earned, and study recommendations. Student can review all questions after completion with explanations. 4.6.2 Timed Challenge Mode A solo mode variant that adds time pressure for exam preparation: Configurable time limit: 30 seconds, 60 seconds, or 90 seconds per question. Visual countdown timer with color-coded urgency (green → yellow → red). Speed bonus: answering correctly within the first 25% of time adds 50% bonus points. Unanswered questions when time expires count as incorrect. 4.6.3 Group Battle Mode Group mode is the flagship competitive feature. It creates real-time, synchronized quiz battles between students. Game Creation Flow: A student (the &#x201C;Host&#x201D;) creates a game room and selects quiz parameters (grade, subject, chapter, difficulty, question count). System generates a unique 6-digit Room Code (e.g., &#x201C;482917&#x201D;). Host shares the Room Code with friends (via in-app share, WhatsApp, or verbally). Other students join the room by entering the code. Minimum 2, maximum 20 players. Host sees a lobby screen showing all joined players with their avatars and levels. Host clicks &#x201C;Start Game&#x201D; when all players have joined. Gameplay Mechanics: All players receive the same questions in the same order simultaneously. Each question has a fixed timer (configurable by host: 15, 20, 30, or 45 seconds). After each question, a live scoreboard animates to show updated rankings. Points per question: base points (by difficulty) + speed bonus (faster answers earn more) + streak multiplier. Between questions, display a &#x201C;fun fact&#x201D; related to the subject to maintain engagement. If a player disconnects, they have 30 seconds to rejoin; otherwise, they receive 0 points for missed questions. Game Resemblance &amp; Fairness System: To ensure fair and exciting competition, the group game engine implements several resemblance and balance mechanisms: Identical Question Set:  All players answer the exact same questions in the exact same order. No randomization of question order between players. Identical Timer:  The countdown timer is server-synchronized. All players see the same remaining time (within 100ms tolerance via WebSocket heartbeat). Answer Lock:  Once a player submits an answer, it&#x2019;s locked. No changes allowed. Anti-Cheat Measures:  Tab-switch detection (warns on first, auto-submits current question on second); copy-paste disabled in quiz interface; device fingerprinting to prevent multi-accounting. Dynamic Difficulty Balance:  If one player is leading by &gt;50% of total points, the system subtly introduces a catch-up mechanic: the leading player&#x2019;s speed bonus is reduced by 25% for the next 3 questions (invisible to players). Real-time Scoreboard:  Animated leaderboard between questions shows position changes with smooth transitions, building excitement. Post-Game Summary: Final rankings with points breakdown (base, speed bonus, streak bonus). MVP Award: player with the highest accuracy (not just most points). Fastest Finger: player with the lowest average answer time. Each player sees their personal performance vs. group average. Option to rematch with same players and new questions. 4.7 Reward &amp; Points System The reward system is designed to create meaningful incentive loops that drive long-term engagement. This feature supports self-directed learning and allows students to study from supplementary materials beyond the official curriculum. 4.8.1 Upload Rules &amp; Restrictions Supported formats: PDF (max 50MB), EPUB (max 30MB), images of textbook pages (JPG/PNG, max 10 pages). Content moderation: AI scans uploaded content for inappropriate material before processing. Personal library: uploaded books are private to the student by default. Sharing option: students can make their uploaded book public for other students at their school (requires admin approval). Storage quota: each student has a 200MB storage limit for personal uploads. 4.8.2 Processing &amp; Quiz Generation Once uploaded, the same AI pipeline used for admin-uploaded textbooks processes the student&#x2019;s book, but with a lighter touch (faster processing, fewer quality checks) to enable rapid quiz generation. Students can generate unlimited quizzes from their personal books. 4.9 Leaderboard &amp; Analytics 4.9.1 Leaderboard Types Class Leaderboard:  Rankings within the student&#x2019;s class/section. Updated in real time. Grade Leaderboard:  Rankings across all sections of the same grade in the school. School Leaderboard:  Top students across the entire school. Displayed on the school&#x2019;s admin dashboard. Subject Leaderboard:  Top scorers per subject (e.g., &#x201C;Top Biology Students&#x201D;). Weekly Champions:  Resets every Monday. Rewards the most active and highest-scoring student of the week. 4.9.2 Anti-Gaming Measures To prevent leaderboard manipulation: Minimum 10 questions per quiz for points to count toward leaderboard rankings. Maximum 20 scored quizzes per day per student (prevents point farming). Accuracy threshold: students scoring below 30% on a quiz receive no leaderboard points. Suspicious activity detection: sudden point spikes trigger automatic review. 4.10 Notification System The notification system keeps all stakeholders informed and engaged through multiple channels: In-App Push Notifications:  Quiz reminders, game invitations, reward eligibility, streak warnings, achievement unlocks, group game results. SMS Notifications:  OTP delivery, weekly progress summary for parents, critical account alerts. Email Notifications (optional):  Detailed weekly/monthly reports for admins, parent progress digests. Users can configure notification preferences with granular control (e.g., mute game invitations but keep reward notifications active). 4.11 Parental Monitoring Portal Designed for low-tech accessibility, the parental portal allows parents to stay connected to their child&#x2019;s educational progress: Link to child&#x2019;s account via phone number verification. View child&#x2019;s quiz history, scores, and rankings. Receive weekly SMS summaries: quizzes taken, average score, rank change, streaks. Set study goals (e.g., &#x201C;Complete 5 quizzes per week&#x201D;) and receive alerts when goals are met or missed. USSD-based access for parents with feature phones (no smartphone required). 4.12 Offline Mode Given Ethiopia&#x2019;s connectivity challenges, offline functionality is a core requirement, not an afterthought: Students can download quizzes for offline use (cached on device for up to 30 days). Offline quiz results are stored locally and synced automatically when connectivity is restored. Textbook chapters can be cached for offline reading. Group games require internet (real-time sync), but solo and timed modes work fully offline. Progressive Web App (PWA) architecture enables installation without app store dependency. 4.13 Multi-Language Support EthioLearn supports the linguistic diversity of Ethiopia: Full UI localization for: Amharic, Afaan Oromoo, Tigrinya, and English. Question generation in the same language as the source textbook. AI translation of questions between supported languages (with confidence indicators). Right-to-left (RTL) layout support for future expansion (Arabic-script languages). Language selector accessible from every screen without requiring a settings page visit.
